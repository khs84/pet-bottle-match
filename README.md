# 빈 페트병 짝 맞추기

초등 과학 「빈 페트병 속에는 무엇이 있을까?」 학습지를 바탕으로 만든 전자칠판용 짝 맞추기 게임입니다.

- 왼쪽 행동 카드(발로 밟기 · 눈으로 보기 · 물속에 넣기)를 누르고, 알맞은 결과 사진을 누르면 선이 이어집니다.
- 안내 음성은 Microsoft 신경망 음성(ko-KR-SunHiNeural)으로 미리 만든 MP3라서 기기마다 목소리가 달라지지 않습니다. MP3를 재생하지 못하면 브라우저 음성(Chrome의 "Google 한국의")으로 대신 읽습니다.
- 음성을 바꾸려면 `make_audio.py`의 문장을 고친 뒤 `pip install edge-tts && python make_audio.py`를 실행합니다.
